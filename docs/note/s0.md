# S0 阶段复盘：守护进程与 CLI 的通信分层

> 对应决策：[ADR 0003](../decisions/0003-s0-followups.md)

## 理解

- 采用 daemon / CLI 分层：`leave-core` 常驻，CLI 作为客户端通过 socket 与之通信。
- 这种服务端-客户端的分层使数据形态非常规整，各实体的职责边界清楚。
- 线协议为 JSON-RPC 2.0，按行分隔（NDJSON）。

## 发现与疑问

1. **同步函数调用异步函数的必要性存疑。** CLI 端发送 ping 时，同步入口里调用了异步函数，当时没有理解这样安排的必要性。

2. **通信协议是本地手写的 socket-server。** 之所以能这样做，是因为客户端与服务端在同一台机器上。若改成 HTTP server 或 WebSocket server，就可以验证「CLI 与 core 分处两台机器时 ping/pong 是否仍然正常」——这也是把 CLI 真正放回客户端位置的前提。

## 遗留

- 跨机器通信未验证；协议替换方案留待后续阶段处理。
